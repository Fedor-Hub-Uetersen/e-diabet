Перелік наданих послуг

📸

ШІ-розрахунок ХО по фото

Завантажте фото страви — вбудований модуль на базі Gemini визначить склад їжі, розрахує вуглеводи та автоматично занесе ХО у ваш щоденник.

📈

Графіки та розрахунок HbA1c

Наочний інтерактивний графік коливань рівня глюкози та автоматичний розрахунок прогнозованого глікованого гемоглобіну (HbA1c) за 90 днів.

🩺

Лікарський портал (Doctor Link)

Генерація захищеного персонального посилання для вашого лікаря, щоб він міг віддалено переглядати графіки без входу у ваш акаунт.

🧮

Калькулятор Хлібних Одиниць

Зручний вбудований калькулятор (1 ХО = 12г вуглеводів) для точного розрахунку будь-якої порції їжі за грамами та вмістом вуглеводів.

🔄

Підтримка mmol/L та mg/dL

Миттєве перемикання одиниць вимірювання глюкози в один клік з автоматичним перерахунком усіх збережених записів та графіків.

🖨️

Експорт та друк у PDF

Формування готового звіту самоконтролю за будь-який період для збереження у форматі PDF або роздруківки перед візитом до лікаря.

🔲

Генератор QR-кодів

Швидке створення та завантаження PNG QR-коду вашого лікарського посилання або профілю для сканування зі смартфона.

🍽️

Каталог продуктів та Преміум

Поповнювана база даних продуктів із підрахунком ХО на 100 грамів, інтеграція із зовнішніми сервісами калорійності.

📱

PWA та Темна тема

Можливість встановлення веб-додатка на головний екран смартфона (Progressive Web App), робота офлайн та підтримка темної теми.
